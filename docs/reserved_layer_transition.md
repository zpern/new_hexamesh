# 保留两层附面层过渡算法

## 1. 目的

规则附面层由三角形源面挤出 Prism、四边形源面挤出 Hexa。不同源面可能因
碰撞、质量、各向同性高度或邻面层差约束而在不同层停止。过渡模块不能直接
保留试生长阶段最后形成的台阶，而要把规则层与外部 Tetra 核心之间的区域
重建为共形的 Pyramid/Tetra 混合网格。

本文记录当前保留层算法的层数定义、高邻边协调规则、既有模板，以及单高邻
边且三个角点继续参与相邻规则体时采用的新模板。

## 2. 试生长与“删除两层”

用户请求每个源点生长 `N` 层时，过渡流程通过
`makeReservedTrialProfiles()` 将试生长层数增加
`ReservedTransitionLayerCount == 2`：

```text
请求层数       N
试生长层数     N + 2
最终规则层数   trial_layers - 2
```

试生长负责确定实际可到达的 front、每个源面的停止层数，以及每个源点从第 0
层到最后试生长层的显式点编号。过渡生成时不直接复制试生长得到的体单元，而是：

1. 复用试生长产生的顶点和逐层点编号；
2. 仅重新生成 `regularLayerCount(trial_layers)` 个规则 Hexa/Prism；
3. 用最后两层留下的点重建 Pyramid/Tetra 过渡区域；
4. 输出去重后的三角形边界层顶面，供外部 Tetra 区域封闭。

因此，“某个下一层点存在”不等于“该点已被规则 Hexa/Prism 使用”。最后两层
的点仍保存在 `LayerVertexTable` 中，但其关联规则体已被删除，点可以被过渡模板
重新使用。

## 3. 层数定义

对一个试生长层数为 `trial_layers` 的源面：

```cpp
regular_layers  = trial_layers > 2 ? trial_layers - 2 : 0;
occupied_layers = trial_layers > 0 ? trial_layers - 1 : 0;
```

- `regular_layers`：最终重新生成的完整规则 Hexa/Prism 数量；
- `occupied_layers`：协调高低邻面时使用的有效占用高度；
- `trial_layers`：试生长实际到达的最高层，包含为过渡预留的两层。

共享边两侧的 `occupied_layers` 最大差值当前限制为 1。低侧面发现相邻面的
`occupied_layers == low + 1` 时，该公共边记为高邻边。

## 4. 过渡协调

`TransitionLayerCoordinator` 在原始 SurfaceTopology 上协调普通单法向路径；
多法向路径通过变换后的 GrowthFront 重新建立边使用关系。协调输出至少包括：

- 每个源面的 `trial_layers / occupied_layers / regular_layers`；
- 第一条高邻边的局部编号；
- 如有相邻的第二条高邻边，其局部编号；
- 单高邻边场景下，是否存在高邻边以外的第三个继续角点。

这里“角点继续”表示该角点的下一层点已经参与相邻源面的规则或过渡占用，
不是指下一层点是否存在。所有预留层点都可能存在。

## 5. Triangle 源面

Triangle 的完整规则层生成 Prism。最后的保留区域根据高邻边状态生成 Pyramid
和 Tetra，并输出三角形顶面。Triangle 不使用 Quad 对角线规则。

## 6. Quad 无高邻边

Quad 的完整规则层生成 Hexa。常规保留区域先在最后一个规则层与下一预留层
之间建立中心点，并生成五个 Pyramid：

- 一个 Pyramid 封闭底部 Quad；
- 四个 Pyramid 覆盖四个侧面；

剩余顶面 Quad 再沿一条对角线分为两个 Tetra。无拓扑约束时，两条候选对角线
分别计算两个三角形的最大等角偏斜度，选择最大偏斜度较小者；分数相同则按
对角线端点编号排序，保证结果确定。

## 7. Quad 单高邻边：两个角点继续

设低层 Quad 的循环顶点及对应下一层点为：

```text
a ----- b        e ----- f
|       |        |       |
c ----- d        g ----- h
```

若唯一高邻边为 `c-d`，且只有该边两个端点对应的上层点参与高侧过渡，则沿用
既有单侧模板：一个 Pyramid 加一个 Tetra。此场景仍允许使用
`chooseQuadDiagonal()` 的几何质量规则选择对角线。

## 8. Quad 单高邻边：三个角点继续

同样令唯一高邻边为 `c-d`，对应上层高边为 `g-h`。若 `a、c、d` 三个角点
继续参与相邻规则体，而 `b` 是唯一未参与规则体的底角，则 `b` 的下一层点
`f` 仍然存在，只是没有被规则 Hexa/Prism 使用。

该场景中，倒数第二层 Quad 不能再自由选择对角线，必须沿 `c-b` 切分。上层
Quad 仍然按质量比较两种合法的 Tetra 分割。若选择 `g-f` 对角线，则使用以下
四个体单元填充：

```text
Pyramid [a, e, g, c, b]
Pyramid [g, h, d, c, b]
Tetra   [e, f, g, b]
Tetra   [f, g, h, b]
```

四个单元共同以唯一未继续角点 `b` 为内部连接顶点。底面三角形为：

```text
[a, c, b]
[c, d, b]
```

通用对角线规则为：

> 将唯一未参与规则体的底角，连接到高邻边中与第三个继续角点相邻的端点。

另一种合法上层分割使用 `e-h` 对角线，对应两个 Tetra 为：

```text
Tetra [e, g, h, b]
Tetra [e, f, h, b]
```

两种上层分割分别取两个 Tetra 全部三角面等角 skewness 的最大值作为方案得分，
并选择得分较小、即最差三角面质量更好的方案（skewness 越接近 0 越好）。
底层的 `c-b` 对角线和两个 Pyramid 保持不变。该拓扑等价于现有相邻双高边
四单元分解的一种定向，可以复用其顶面对角线质量选择逻辑。

## 9. Quad 相邻双高边

当两条相邻边都是高邻边时，现有模板以两条高边的公共角点确定局部方向，
生成两个 Pyramid 和两个 Tetra。两种合法的上层 Tetra 对角线目前按最坏
三角形 skewness 选择。两条相对高边不接受，因为现有局部模板无法保证共形。

## 10. 0 层停止面

实际生长 0 层的源面不会保留任何附面层体单元，因此它不应选择高邻边，也不
应通过高邻边的非接触角点把一环源面直接压到 0。共享边层差传播仍然保留，
以 `max_layer_diff` 逐圈限制邻面层数。

## 11. 共形与有效性要求

所有模板必须满足：

1. 相邻体单元的公共界面节点集合和三角剖分完全一致；
2. 任一内部 Triangle/Quad 恰有两个体单元拥有者；
3. 外露顶面恰有一个体单元拥有者；
4. 不产生正体积交叉、翻转或零体积单元；
5. 单元元数据保留 `source_face_id`、`layer` 和 `cell_role`，便于从结果反查模板。

当拓扑规定了对角线时，共形要求优先于单个源面的局部质量最优；只能在同一
拓扑下比较不同定向或分解的质量。
