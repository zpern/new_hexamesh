# 逐层附面层过渡设计

## 1. 目标

将现有“额外试生长两层，生长结束后一次性重建过渡区”的流程改为逐层事务式过渡：每次从第 `n` 层前沿预生长第 `n+1` 层，立即完成停止面协调、角点压制、过渡单元生成和联合相交检测，迭代到本层稳定后再提交。

任意直接相邻面之间的最终层差必须始终为 0 或 1。整体区域可以通过连续的一级台阶形成累计两层、三层或更大的高度差。

最终附面层外表面必须完全由 Triangle 组成。规则区继续使用 Prism/Hexa；每一级台阶以及 Quad 最顶层使用现有 Pyramid/Tetra 模板。

## 2. 取消两层预留

新主流程不再调用 `makeReservedTrialProfiles()` 为用户请求统一增加两层，也不再依赖 `trial_layers`、`occupied_layers` 和 `regular_layers` 三套层数语义。

用户请求的层数就是最大正式生长层数。每轮只预生长下一层，候选通过当层固定点求解后才进入正式网格。

现有最终一次性调用的 `generateReservedLayerTransition()` 被逐层过渡结果取代。已有 Triangle、Quad、对角线选择和单元质量代码应尽量作为局部模板复用。

## 3. 所有层使用同一流程

第 `0→1` 层与后续层没有流程例外：

```text
第 n 层正式前沿
    ↓
预生长第 n+1 层（n >= 0）
    ↓
建立 stop1 与 stop2
    ↓
角点压制
    ↓
生成本层全部顶盖和侧向过渡单元
    ↓
联合暴露面相交检测
    ↓
相交回退并重复，直到固定点
    ↓
原子提交第 n+1 层稳定结果
```

从第 0 层向第 1 层推出时，同样必须构造过渡单元并进行联合检测，不能先生成一层规则单元、到第二层才开始过渡。

## 4. 两套停止集合

每层维护两个语义不同的集合：

```text
stop1：角点压制的驱动种子
stop2：当前停留在第 n 层、必须参与过渡区生成的全部低面
```

完成第 `n+1` 层预生长后，所有非角点原因停止的第 `n` 层面同时加入 `stop1` 和 `stop2`。这些原因包括：

- 达到用户请求层数；
- 候选退化、反转、局部反转或 skewness 超限；
- 障碍物碰撞或本层自相交；
- 滑移投影失败；
- 当前单元已接受但达到各向同性停止条件。

集合更新规则为：

| 低面来源 | 加入 `stop1` | 加入 `stop2` |
|---|---:|---:|
| 初始非角点停止 | 是 | 是 |
| 过渡区相交导致高单元回退 | 是 | 是 |
| 角点压制导致高单元回退 | 否 | 是 |

角点压制产生的低面不得加入 `stop1`，避免递归压制扩散到整层；但它们必须加入 `stop2`，以便重新生成完整、共形的过渡区。

新实现应使用显式层号和来源，而不是依赖当前 `pending_stop_cells` 的 `step.layer - 1` 隐式推导：

```cpp
struct LayerStopState
{
    SurfaceFaceId source_face_id{};
    std::uint32_t completed_layer{};
    StopOrigin origin{};
};
```

## 5. 当层固定点循环

第 `n+1` 层作为尚未提交的事务处理：

1. 以所有通过初始质量和碰撞检查的第 `n+1` 层候选作为高单元集合。
2. 初始化非角点停止面，并同时写入 `stop1` 和 `stop2`。
3. 只遍历尚未处理的 `stop1`，检查其当前高邻边并执行角点压制。
4. 删除被角点压制的高单元，将其第 `n` 层低面只加入 `stop2`。
5. 废弃旧的临时顶盖和侧向过渡，按完整 `stop2` 及当前高单元集合重新生成。
6. 对规则高单元、顶盖和侧向过渡形成的完整联合暴露面做相交检测。
7. 若发生相交，删除相交过渡区依赖的全部第 `n+1` 层高单元，将其低面同时加入 `stop1` 和 `stop2`，返回步骤 3。
8. 若本轮没有新增高单元删除，固定点达到稳定，原子提交事务结果。

每轮收集全部冲突高面后批量删除，不能遇到第一个冲突就提交局部修改。高单元在同一事务中只允许从保留集合删除、不能恢复，因此固定点循环单调终止，迭代轮数不超过本层初始高候选面数量。

## 6. Quad 角点压制规则

对每个 `stop1` Quad，基于当前仍保留的第 `n+1` 层高单元收集高邻边：

| 高邻边状态 | 保留方案 | 压制规则 |
|---|---|---|
| 0 条 | 空方案 | 不压制 |
| 1 条 | 保留该边 | 沿用现有单高邻边规则 |
| 2 条且相邻 | 保留两条 | 只压制唯一不属于两条高边的角点一环高单元 |
| 2 条且相对 | 枚举保留其中一条 | 对所选边使用单高邻规则 |
| 3 条 | 枚举所有相邻边对 | 压制所选边对无关角点一环及未保留高邻 |
| 4 条 | 枚举四组相邻边对 | 同上 |

存在多个合法保留方案时，为每个方案临时生成对应局部模板，并使用模板全部三角面的最大 equiangle skewness 评分：

```text
score = max(候选模板全部三角面的 skewness)
```

选择分数最小的方案。分数相同时，先比较排序后的高邻源面 ID 序列，再比较 Quad 局部边编号，保证结果与遍历顺序无关。

所有角点压制删除的高单元只产生 `stop2`，不能产生新的 `stop1`。

## 7. 顶层 Quad 剖分和全三角形外表面

每个 Quad 柱只有当前最顶层 Hexa需要剖分。取该 Hexa 的底层 Quad `bottom`、顶层 Quad `top` 和八点几何中心 `c`，复用现有公共基础块：

```text
1 个底面 Pyramid
4 个侧面 Pyramid
2 个顶面 Tetra
```

即 `5 Pyramid + 2 Tetra`。两个 Tetra 的外露顶面将 `top` Quad 切成两个 Triangle，对角线继续按现有质量和确定性决胜规则选择。

具体规则：

- Quad 柱成功进入第 1 层时，第一个 Hexa就作为最顶层剖分，不能直接保留完整 Hexa。
- Quad 柱从第 `n` 层成功继续到第 `n+1` 层时，第 `n` 层旧顶盖恢复为完整 Hexa，第 `n+1` 层 Hexa成为新的 `5 Pyramid + 2 Tetra` 顶盖。
- Quad 柱停在第 `n` 层且邻接第 `n+1` 层高单元时，在其顶盖基础上追加现有一级侧向 Pyramid/Tetra 模板。
- Quad 柱停在第 0 层时没有 Hexa可拆，直接将源 Quad 按质量规则切成两个外露 Triangle；若存在第 1 层高邻，仍必须生成 `0→1` 侧向过渡模板。
- Triangle 柱的 Prism 顶面天然是 Triangle，不需要 Quad 顶盖剖分；一级台阶继续使用现有 Triangle 过渡模板。

顶盖必须视为每层事务中的可替换派生结果，不能过早永久写入正式网格。

## 8. 联合暴露面检测与回退归属

每轮检测对象是以下内容形成的完整联合暴露面：

- 当前保留的第 `n+1` 层规则高单元；
- 所有 Quad 最顶层剖分；
- 由完整 `stop2` 生成的全部侧向过渡单元。

联合暴露面同时检查：

- 原始表面；
- 已提交的历史暴露边界；
- 本层候选之间的自相交。

每个碰撞三角形应携带源面、层号和角色归属，以支持精确回退：

```cpp
struct LayerBoundaryOwner
{
    SurfaceFaceId source_face_id{};
    std::uint32_t layer{};
    BoundaryOwnerRole role{};
};
```

回退规则：

- 规则高单元外露面相交：删除该高单元。
- 顶盖相交：删除产生该顶盖的第 `n+1` 层高单元。
- 侧向过渡相交：删除该模板依赖的全部第 `n+1` 层高单元。
- 两个本层候选相交：删除双方涉及的高单元。
- 原始表面、历史暴露边界和第 `n` 层及以下正式单元不可回退。

相交回退产生的新低面同时加入 `stop1` 和 `stop2`，因此必须重新执行角点压制并按完整 `stop2` 重建全部临时过渡单元。

## 9. 事务边界与组件职责

新增逐层协调组件，例如 `LayerTransitionResolver`：

```cpp
struct StableLayerTransition
{
    LayerStepResult retained_regular_step;
    VolumeMesh top_cap_mesh;
    VolumeMesh side_transition_mesh;
    ExposedBoundaryUpdate boundary_update;
    std::vector<LayerStopState> stopped_faces;
};
```

它接收正式第 `n` 层 front、预生长结果、历史暴露边界、原始表面碰撞索引、拓扑和点号映射，在内部执行固定点循环，返回尚未写入正式网格的稳定结果。

`RegularLayerGenerator` 负责：

```text
预生长 → 调用 LayerTransitionResolver → 原子提交 → 构建下一层 front
```

提交时统一更新：

- 规则 Prism/Hexa；
- Quad 顶盖和侧向过渡单元；
- `LayerVertexTable`；
- `FaceGrowthRecord`；
- 单元元数据；
- 正式 `ExposedBoundaryTracker`；
- 下一层 `GrowthFront`。

## 10. 不变量和错误处理

提交前必须同时满足：

1. 任意直接共享边两侧的接受层数差不超过 1。
2. `stop1` 已无未处理种子，本轮没有新增角点压制或相交回退。
3. 完整 `stop2` 中每个低面都能由现有模板表达。
4. 联合暴露边界与原始表面、历史边界和自身均无非法相交。
5. 所有最终外露面均为 Triangle。
6. 内部 Triangle 恰有两个体单元拥有者，外露 Triangle 恰有一个拥有者。
7. 所有体单元不反转、不退化，不产生正体积交叉。
8. `mesh.cells.size() == mesh.metadata.size()`。
9. 每个单元保持可追踪的 `source_face_id`、`layer` 和 `cell_role`。

无法生成某个临时模板时，若可通过删除其依赖的本层高单元隔离，则按相交回退处理。以下情况返回硬错误：

- front、源面、点号或层点映射损坏；
- 已提交历史边界自身非法；
- 几何质量计算失败且无法通过本层回退隔离；
- 固定点结束后仍存在层差违规、模板缺口或非法相交；
- 网格和元数据数量不一致。

## 11. 测试策略

采用测试驱动方式实现，至少覆盖：

- `0→1` 层存在低面和高邻时生成过渡单元；
- 一层 Quad 的唯一 Hexa被剖分为 `5 Pyramid + 2 Tetra`；
- 无过渡 Quad 柱也只剖分当前最顶层 Hexa；
- 柱继续生长时旧顶盖恢复为完整 Hexa，新顶层成为顶盖；
- 初始非角点停止同时进入 `stop1` 和 `stop2`；
- 角点压制产生的低面只进入 `stop2`，不会递归压制；
- 相交回退产生的低面同时进入 `stop1` 和 `stop2`；
- 回退后重新执行角点压制并重建完整过渡区；
- Quad 具有 0、1、相邻 2、相对 2、3、4 条高邻边的全部分支；
- 多方案以最差 skewness 选择，平分时结果确定；
- 多级阶梯整体累计高度差为 2、3 或更多，同时任意直接邻面层差不超过 1；
- 本层多个冲突批量回退，结果不依赖面遍历顺序；
- Triangle/Quad 混合 front；
- 第 0 层 Quad 无高邻时直接输出两个 Triangle；
- 最终顶面全为 Triangle，内部面和外露面拥有者计数正确；
- 无反转、退化、非法相交，网格与元数据数量一致。
