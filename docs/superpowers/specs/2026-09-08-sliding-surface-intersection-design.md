# 常规边界层滑移面相交检测设计

## 1. 背景与目标

当前常规边界层生成使用 `CollisionIndex` 检测输入障碍面、历史暴露边界和同层候选单元，但 `CollisionBoundaryPolicy` 会排除 `Symmetry` 与 `Internal`。这两个边界承担滑移约束：合法生成的侧面可能与它们点接触、沿边接触或近似重合，因此不能直接作为普通障碍面加入现有碰撞索引。

本次仿照旧 `blmesh` 的对称面检测设计，为 `Symmetry` 和 `Internal` 建立独立的静态滑移面相交检测路径。目标是允许符合拓扑约束的贴面接触，同时拒绝候选常规层单元穿过滑移面或撞到其他滑移区域。

本次只覆盖常规逐层生成，不修改多法向过渡单元的相交解析流程。

## 2. 设计原则

1. 普通障碍碰撞与滑移面碰撞保持两条独立路径。
2. 滑移面查询使用几何坐标，不依赖候选前沿与输入表面共享节点编号。
3. 合法接触由顶点继承的 `sliding_region_ids` 和候选面的真实拓扑边决定。
4. 权限以 `region_id` 为作用域，对一个区域的合法接触不得屏蔽与另一区域的碰撞。
5. `Symmetry` 与 `Internal` 使用相同算法，但保留各自 `SurfaceBoundaryKind`。
6. 非有限坐标、退化候选和无法完成局部方位判断的情况保守地判为失败或保留碰撞。

## 3. 总体架构

输入表面构建两类索引：

```text
输入 SurfaceMesh
  ├─ 普通障碍面 ─────────────> 现有 CollisionIndex
  └─ Symmetry / Internal ────> 新增 SlidingIntersectionIndex

常规层候选单元
  ├─ 顶面和侧面三角形 ───────> CollisionIndex
  └─ 带区域接触权限的坐标 ───> SlidingIntersectionIndex

任一路径发现非法相交 ────────> 现有 FaceStopReason::Collision 流程
```

新增模块建议位于 `spatial`：

- `sliding_intersection.hpp/.cpp`：三角形交集分类、接触权限和同侧分类；
- `sliding_intersection_index.hpp/.cpp`：滑移面静态三角形集合、AABB 树查询、指定区域的局部法向和有符号侧值。

`LayerCollisionChecker` 负责从候选棱柱构造带角色和真实边信息的查询，并组合普通障碍与滑移面结果。

## 4. 静态滑移面索引

索引从完整 `SurfaceMesh` 中收集 `SurfaceBoundaryKind::Symmetry` 和 `SurfaceBoundaryKind::Internal` 面。三角面直接加入；四边形沿工程既有固定对角线拆成两个三角形。每个三角形记录：

- 三个坐标；
- `boundary_kind`；
- `region_id`；
- 源面编号和局部三角形编号，用于诊断和测试。

粗筛复用 `BinaryAabbTree`。索引构建时拒绝以下输入：

- 面标签数量与面数量不一致；
- 节点索引越界；
- 坐标非有限；
- 三角形退化；
- AABB 或树构建失败。

`region_id` 是接触权限的身份键。现有 `SlidingSurfaceBuilder` 已要求一个 `region_id` 不能同时属于不同边界类型，因此可继续使用当前 ID 域，无需引入复合键。

## 5. 候选棱柱查询

`buildLayerBoundaryCandidates` 已提供一个候选单元的底面、顶面和逐条侧边的滑移标签。实现将补充或内部派生每个顶点继承的排序去重 `sliding_region_ids`，使权限不依赖单个侧面标签。

一个三角形前沿产生的棱柱检查三个侧四边形和一个顶面；四边形前沿产生的六面体检查四个侧四边形和一个顶面。侧四边形固定拆分为：

```text
T0 = {lowerA, lowerB, upperA}
T1 = {lowerB, upperA, upperB}
```

物理边掩码为：

- `T0`：下边和 `lowerA-upperA` 生长边；
- `T1`：上边和 `lowerB-upperB` 生长边；
- 人工对角线 `lowerB-upperA` 不属于物理边。

顶面按其真实三角形边查询。四边形顶面拆分时，同样不给人工对角线权限。

## 6. 按区域划分的接触权限

每个候选三角形针对每个关联 `region_id` 构造一份权限：

- `vertex_mask`：候选顶点属于该滑移区域时，对应位为 1；
- `edge_mask`：只有一条明确标记为物理边，且两端都属于该区域时，对应位为 1；
- `complete_face_exemption`：仅侧四边形四个上下节点都属于同一区域时为真。

规则如下：

1. 单个允许顶点只能放行落在该顶点容差邻域内的交集。
2. 允许物理边可以放行完全位于该边容差邻域内的点或线段交集。
3. 完整侧四边形可对同一 `region_id` 跳过精确相交，以容纳曲面离散和再次投影误差。
4. 顶面永远不能获得完整面豁免。
5. 未授权的共面面积重叠、进入候选内部的交线或穿透均为非法。
6. 对区域 A 的权限只应用于索引中区域 A 的三角形。

## 7. 精确相交分类

三角形交集返回以下几何类别：

```cpp
enum class SlidingIntersectionKind {
    Empty,
    Points,
    Segments,
    CoplanarArea
};
```

非共面情况通过双方三条边与对方平面的裁切收集交点，去重后分类为点或线段。共面情况投影到主轴二维平面，使用多边形裁剪判定无交集、点、线段或正面积重叠。

非法相交判断顺序：

1. 验证输入坐标有限；
2. 检查当前区域的完整侧面豁免；
3. 使用 AABB 粗筛；
4. 对重叠的退化三角形保守拒绝；
5. 无几何交集则通过；
6. 未豁免的共面面积交集拒绝；
7. 点和线段交集全部落在当前区域允许的顶点或物理边上则通过；
8. 其他情况拒绝。

容差按候选三角形和表面三角形的坐标及边长缩放：

```text
max(1e-10, 64 * machine_epsilon * geometry_scale)
```

二维叉积判断使用 `distance_tolerance * clip_edge_length`，保证量纲一致。

## 8. 曲面自身区域的同侧修正

候选单元命中自身关联的曲面滑移区域时，可能只是上下投影点之间的弦穿过离散三角片，而非单元真实跨面。为避免该类假碰撞，对整个候选棱柱或六面体执行局部同侧判定：

1. 一列只有在下层点和对应上层点都包含命中的 `region_id` 时，才属于该区域。
2. 至少一列属于该区域且并非全部列都属于该区域时，允许尝试同侧修正。
3. 在某个关联上层点附近查找该区域的最近非退化三角片，取得参考法向。
4. 对所有非关联列的上下点，计算其到该区域最近三角片的有符号侧值；局部法向先翻转到与参考法向同向。
5. 如果有效侧值没有同时出现小于 `-1e-10` 和大于 `1e-10` 的值，则它们处于同侧或容差带内，只忽略本次命中的自身区域。
6. 忽略后重新查询同一候选三角形，确保与其他 `Symmetry` 或 `Internal` 区域的碰撞仍被发现。

以下情况不放行：没有完整的上下列关联、所有列都关联、找不到指定区域的局部三角片、法向退化、数据非有限，或非关联点分布在曲面两侧。

与旧 `blmesh` 相比，本工程还支持四边形前沿。算法不固定为三列，而是对候选单元的全部上下对应列应用相同规则。

## 9. 常规生长集成

规则层生成初始化阶段同时构造：

- 现有原始表面 `CollisionIndex`；
- 新的 `SlidingIntersectionIndex`；
- 现有 `SlidingSurfaceSet`，继续负责方向约束和位置投影。

`LayerCollisionChecker::filterAgainstObstacles` 对每个候选单元执行：

```text
普通输入表面命中
  OR 历史暴露边界命中
  OR 滑移面非法相交
```

命中后继续使用现有 `compactStep`，记录 `FaceStopReason::Collision`。同层自碰撞仍使用现有 `CollisionIndex`，因为它比较的是候选单元之间的碰撞，不需要滑移面接触权限。

为控制本次范围，多法向过渡生成器和 `resolveMultiNormalLengths` 不接入新索引。

## 10. 错误处理

滑移面索引构建错误通过现有 `SpatialError` 返回；若现有枚举无法明确表达标签不匹配、退化滑移三角形或无效区域数据，则添加聚焦的错误项。生成器遇到构建错误不返回部分网格。

单个候选包含非有限坐标或无法构造查询 AABB时返回错误，而不是当作无碰撞。局部同侧判定无法可靠完成时，仅取消豁免并保留原始碰撞结论。

## 11. 测试与验收

### 11.1 精确几何单元测试

- 无权限穿透必须拒绝；
- 单个允许顶点接触通过，但从顶点延伸到内部拒绝；
- 允许物理边接触通过，但超出该边拒绝；
- 共面面积仅在完整侧四边形豁免时通过；
- 人工对角线不获得边权限；
- 非有限和退化输入保守失败；
- 大坐标、长边和近容差边界保持稳定。

### 11.2 索引单元测试

- 同时收集 `Symmetry` 与 `Internal`；
- 坐标查询不依赖节点 ID；
- 区域 A 的权限不能屏蔽区域 B；
- 指定区域的最近法向和正负有符号侧值正确；
- 忽略合法自身区域后仍可命中其他区域；
- 查询包围盒位于树外时安全返回无命中。

### 11.3 权限和同侧测试

- 三角形及四边形候选的真实边掩码正确；
- 完整侧四边形公共区域计算正确；
- 一列、多列关联以及全部列关联的分类正确；
- 非关联点同侧时允许忽略自身区域；
- 非关联点跨越正负两侧时保留碰撞。

### 11.4 常规生长集成测试

- 合法沿平面 `Symmetry` 生长不停止；
- 合法沿平面 `Internal` 生长不停止；
- 候选棱柱穿过 `Symmetry` 时停止；
- 候选棱柱穿过 `Internal` 时停止；
- 贴合自身区域时仍能检测另一个滑移区域；
- 曲面滑移区域的离散弦误差不产生假停止；
- 普通障碍、历史边界和同层自碰撞行为保持不变；
- 多法向过渡测试保持原行为。

### 11.5 `symm_intersection` 真实案例回归

旧 `blmesh` 的 `build/input/symm_intersection/BoundaryMeshing.txt` 是唯一的原始案例输入，它同时保存边界层参数、几何面边界类型、全部表面点和全部表面三角形。`input_surface.vtk` 是 `vmesh_test` 读取该文件后写出的同一表面网格，仅作为可视化副产物，不作为第二份输入或第二个案例。

测试数据应把 `BoundaryMeshing.txt` 复制到当前工程的受版本控制测试夹具目录，避免自动测试依赖相邻旧工程的绝对路径。添加测试专用的严格读取器，沿用旧 `blmesh/vmesh/src/main.cpp::readBoundaryMeshing` 的字段顺序、1 基点 ID 和三角形记录规则，并直接构造当前工程的 `SurfaceMesh` 与逐源点生长 profile。不要在测试中再次读取 `input_surface.vtk`，也不要为此旧调试格式增加生产级 I/O API。

经旧 `blmesh` 的解析和 API 参数传递代码确认，案例全局参数及含义为：

```text
nLN = 20                         # 最大边界层层数
dLen = 0.10000000100000001       # 默认第一层高度
dRto = 1.19999999999999996       # 默认层高增长率
max_prism_skewness = 1.0         # 棱柱最大等面积偏斜度
max_pyramid_skewness = 1.0       # 金字塔最大等面积偏斜度
max_ratio_diff = 0.25            # 相邻区域层高/过渡尺寸比例限制
bisostop = 1.0                   # 各向同性停止高度
b_use_multiple_normals = 0       # 关闭多法向
```

`boundary_info` 将几何面 ID 映射为旧边界类型：`0=Farfield`、`1=Wall`、`2=Symmetry`、`3=Match`、`4=Periodic`、`5=Adjacent`。本案例中面 `0,1,2,4,5` 为 Wall，面 `3` 为 Symmetry。

`variable_para` 是按几何面 ID 的覆盖参数，条目依次为 `face_id, layer_count, first_height, growth_ratio`。本案例必须原样映射：

```text
face 0,1,2,4,5: 20 layers, first height 0.10000000100000001,
                  growth ratio 1.19999999999999996
face 3:            0 layers, first height 0.000000001, growth ratio 0.0
```

在当前工程中仅 Wall 面进入 `GrowthPatch`，所以 face 3 的零层配置由边界类型自然满足；其余五个 Wall 区域的 profile 必须使用上述覆盖值。当前常规生成 API 没有金字塔生成路径，也没有与旧实现完全同名的 `max_pyramid_skewness`、`max_ratio_diff` 和 `bisostop` 控制项；这些值应由夹具读取并校验不变，但只把当前 API 有对应语义的层数、首层高度、增长率和棱柱质量阈值传入生成流程，不伪造错误的参数对应关系。

输入中的边界区域 3 是滑移检测目标，其余区域保持原边界角色。用完全相同的几何和生长参数运行两个变体：

1. 区域 3 标记为 `SurfaceBoundaryKind::Symmetry`；
2. 区域 3 标记为 `SurfaceBoundaryKind::Internal`。

测试必须记录修改前基线：在禁用新增滑移面检测、仅保留现有普通障碍检测时，至少存在一个常规候选单元与区域 3 的非法相交。这个基线用于证明夹具确实覆盖缺陷，不作为长期“应通过”的产品行为。

启用新增检测后，两个变体均须满足：

- 生成过程成功完成或按碰撞规则局部停止，不产生非法穿越单元；
- 对最终接受的常规层单元重新执行独立的滑移面交叉审计；
- 区域 3 与生成边界之间不存在未授权的点、线段或面积交集；
- 由共同 `region_id` 授权的公共顶点、真实物理边和完整贴面侧四边形不计为非法相交；
- `Symmetry` 与 `Internal` 两个变体的停止/接受决策在相同几何条件下保持一致。

验收除断言外保留两个案例的 VTK 输出，分别使用不同文件名，供 ParaView 人工对比。测试不得覆盖用户提供的旧工程输入和输出文件。

验收命令以项目现有 CMake 配置为准，至少运行新增目标、空间模块测试、常规层单元与集成测试，并最终运行完整 CTest。

## 12. 非目标与限制

- 不检测多法向过渡单元与滑移面的相交；
- 不修改滑移投影算法；
- 不把滑移面插入动态历史边界索引；
- 完整侧四边形豁免以 `region_id` 为粒度；同一区域自身折叠造成的远端相交可能被该豁免隐藏，此类输入视为无效滑移面；
- 当前局部同侧判定适用于简单、连续的曲面，不提供全局内外分类或自适应细分。
