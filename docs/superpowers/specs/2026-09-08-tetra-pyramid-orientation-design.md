# Tetra/Pyramid 统一绕向设计

## 目标

统一边界层网格中 Tetra 与 Pyramid 的节点语义，使所有正常过渡模板按固定拓扑绕向直接生成正有向体积单元。禁止依据生成后的体积符号交换节点，因为这种修正会掩盖真实的几何反转、穿插和局部翻转。

## 统一约定

- Tetra 保存为 `0,1,2,3`：`0-1-2` 是有向基面，点 `3` 位于该基面的正体积侧；有向体积定义为 `dot(p1-p0, cross(p2-p0, p3-p0))/6`，正常构型必须为正。
- Pyramid 保存为 `0,1,2,3,4`：`0-1-2-3` 是连续环绕的四边形基面，`4` 是顶点。其固定子四面体分解必须全部具有正有向体积；出现负值、正负混合或零值分别视为整体反转、局部反转或退化。
- Prism/Hexa 的既有节点约定保持不变。

## 生成规则

逐一修正以下模板，使节点编号由模板拓扑和输入面的绕向确定，不依赖坐标计算后的符号：

- `buildTriangleSideTransition`
- `buildQuadTopCap`
- `buildQuadSideTransition`
- `buildQuadAdjacentSideTransition`
- `buildMultiNormalTransition`

多法向构造器当前在 Tetra 体积为负时交换节点 `1/2`。该行为必须删除；各分支应根据输入三角面的局部绕向和 lower/upper 节点语义直接给出统一顺序。体积计算仅用于拒绝非有限或退化构型以及测试/诊断，不参与改写连接关系。

## 验证与错误暴露

增加 Tetra/Pyramid 的公共只读质量判断或等价测试辅助逻辑：

- 所有固定子四面体为正：有效；
- 所有固定子四面体为负：整体反转；
- 子四面体正负混合：局部反转；
- 任一必要子体积为零：退化。

模板生成阶段不对负体积自动换点。正常夹具若产生负体积，测试应失败，从而定位模板绕向错误；真实几何造成的反转继续保留为可诊断故障。

## 导出

Legacy VTK 中 `VTK_TETRA(10)` 与 `VTK_PYRAMID(14)` 使用内部统一节点序直接输出，不执行基于几何符号的换点。测试将解析写出的 connectivity，并用相同有向体积约定验证正常模板输出。

当前工程只提供 CGNS 表面读取，没有 CGNS 体网格写出路径，因此本次没有可修改的 CGNS volume writer。未来增加 CGNS 体网格导出时，应通过显式、固定的内部顺序到 CGNS 标准顺序映射实现，仍不得按体积符号动态换点。

## 测试策略

按 TDD 顺序实施：

1. 为统一 Tetra/Pyramid 约定增加标准正向、整体反向、局部反转和退化测试。
2. 扩充每个过渡模板测试，使用实际坐标检查其所有 Tetra/Pyramid 固定子体积为正；先确认现有代码能复现负体积失败。
3. 增加多法向回归测试，证明构造器不再通过体积后处理交换节点，并且正常拓扑仍输出正向单元。
4. 扩充 VTK writer 测试，验证导出 connectivity 与内部约定一致。
5. 运行相关 unit、过渡 pipeline integration 和完整 CTest。

## 非目标

- 不按符号自动修复任意外部输入的体单元。
- 不改变 Prism/Hexa 的节点顺序或质量判据。
- 不借本次修改重构无关的过渡、碰撞或表面拓扑逻辑。
