# 双高邻边四面体方案选择设计

## 目标

双高邻边四边形仍从两条高邻边的公共角点连接到对角点，保持强制对角线和现有两个金字塔不变。剩余空间不再固定使用一组四面体，而是在两种合法组合之间按最大 skewness 最小原则选择。

## 候选方案

局部点命名沿用双高模板：底层为 `a, b, c, d`，高层为 `e, f, g, h`，其中 `a` 是两条高邻边的公共角点，强制对角线为 `a-d`。

- 方法一：`egfd` 与 `gfhd`
- 方法二：`eghd` 与 `efhd`

两个金字塔保持为 `abfed` 与 `aegcd`。

## Skewness 计算与选择

每个四面体的 skewness 复用现有三角形等角偏斜度算法：分别计算四面体四个三角形面的 `triangleEquiangularSkewness`，取四个面的最大值作为该四面体的 skewness。

每种方法的方案分数是其两个四面体 skewness 的最大值：

```text
score1 = max(skewness(egfd), skewness(gfhd))
score2 = max(skewness(eghd), skewness(efhd))
```

保留分数较小的整套方法。分数完全相同时固定保留方法二，以维持当前行为并保证输出可重复。

## 错误处理

若一种方法因退化三角形等原因无法得到 skewness，则选择另一种可计算的方法。若两种方法都无法计算，则返回现有过渡模板错误，不生成不确定的体单元。

## 测试

在四边形过渡模板单元测试中增加几何用例，验证：

1. 方法一分数较小时输出 `egfd`、`gfhd`；
2. 方法二分数较小时输出 `eghd`、`efhd`；
3. 分数相同时保持方法二；
4. 两个金字塔、顶面输出和单高邻边逻辑不受影响。
