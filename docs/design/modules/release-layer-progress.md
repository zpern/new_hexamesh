# 逐层生成进度输出

## 目标

规则边界层生成在 Debug 和 Release 构建中直接向标准输出报告每层的开始、
结束及该层实际提交的体单元数量，便于长时间真实案例观察进度。

## 输出格式

目标层开始预推出前输出：

```text
generate 1 boundarylayer
```

该层通过质量、碰撞和终止传播并正式提交后输出：

```text
finish 1 boundarylayer. add 10000 cell
```

层号使用目标层号，从 1 开始；新增单元数使用本层最终
`new_cells.size()`，不使用累计单元数。

## 实现位置

输出直接放在 `RegularLayerGenerator::generate()` 的逐层循环中：

1. 循环开始、调用 `RegularLayerStepper::step()` 前输出开始行；
2. 本层顶点、体单元、元数据和外露边界成功提交后输出结束行；
3. Debug 和 Release 使用完全相同的输出行为；
4. 使用 `std::cout << ... << std::endl`，确保长任务每层及时刷新；
5. 如果本层提交零个单元，仍输出 `add 0 cell`；
6. 如果本层在提交前返回程序错误，只保留开始行，不输出虚假的结束行。

## 测试

- 测试捕获标准输出，验证两层案例严格输出两组开始/结束行；
- 验证每层新增单元数而非累计单元数；
- Debug 全量回归确认默认测试输出和算法结果不变；
- Release 全量回归后运行 2dot5 案例十层，记录每层新增量和最终体单元数。
