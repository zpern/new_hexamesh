# BoundaryMesh 功能路线

本文只描述当前项目的功能分层和后续维护方向，不记录已经删除的实施计划。

## 已形成的功能链

1. 基础类型、结果/错误模型和 CMake 库目标。
2. 混合表面/体网格与封闭表面拓扑。
3. 表面几何评价、GrowthPatch 和 GrowthFront。
4. 法向、步长、对称面和多法向约束。
5. Prism/Hexa 规则层生成与逐层事务提交。
6. 体单元有向体积、退化和质量检查。
7. 空间查询、合法接触识别、碰撞回退和局部停止。
8. 层数协调、停止传播和局部过渡。
9. Pyramid/Tetra/滑移接口等边界层过渡。
10. CGNS/VTK 输入输出、命令行运行和真实案例验证。

## 当前维护重点

- 使公共接口、模块设计文档和实际头文件保持一致；
- 为每个新增几何规则补充单元测试和集成测试；
- 保持候选生成的事务边界，避免失败候选污染已提交网格；
- 继续改进复杂角点、层数不一致和合法共享接触的鲁棒性；
- 对 Release 构建、真实网格和 VTK/ParaView 检查脚本进行回归。

## 后续方向

- 完善不同输入格式和边界条件的统一适配；
- 扩展大规模网格的内存和运行时间测试；
- 将稳定的 BoundaryMesh 库接口集成到上层应用；
- 对过渡模板、方向约定和停止原因提供更完整的诊断输出。

路线中的“后续方向”不是当前实现承诺；实际行为以源码、测试和 `README.md` 为准。
