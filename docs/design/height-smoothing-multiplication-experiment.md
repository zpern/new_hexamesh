# 步长平滑乘法实验设计

## 目标

验证步长平滑修正采用乘法后，`2dot5_cf` 边界层的生成结果。

## 改动范围

- 将实际步长公式从 `base_height / (1 + correction)` 改为 `base_height * (1 + correction)`。
- 保留当前 Logistic 响应系数 `0.5`。
- 保留活动前沿、法向平滑、步长 `50%～150%` 限制以及所有质量、碰撞和停止规则。
- 不增加运行时配置开关，本次直接替换默认行为。

## 验证

1. 修改步长平滑单元测试，使其明确验证乘法公式，并先确认测试在旧实现上失败。
2. 修改生产实现并确认对应单元测试通过。
3. 运行完整 Debug 回归测试。
4. 构建 Release，并使用首层步长 `0.1`、增长率 `1.2`、20 层、最大 skewness `0.9`、各向同性停止阈值 `1.0` 测试 `2dot5_cf`。
5. 报告逐层新增单元数、总体单元数和停止原因统计，并与此前除法策略结果对比。
